# Бот для хостинга (bothost)
Файл запуска: `bot.py`, команда: `python bot.py`, зависимости: `requirements.txt`.
ВАЖНО: загружай ВСЕ файлы (включая картинки .jpg и шрифты .ttf) в одну папку рядом с bot.py.
Переменные окружения:
- `BOT_TOKEN` — токен от @BotFather (обязательно)
- `OWNER_ID` — ID админов через запятую (по умолчанию уже заданы)
- `DB_PATH` — путь к базе на постоянном диске, напр. `/data/bot.db` (иначе база сотрётся при редеплое)
- `MANAGER`, `PAYMENT_DETAILS`, `CHANNEL_URL`, `REVIEWS_URL`, `REVIEWS_CHAT` — по желанию, меняются и в /admin.
Админ-панель: `/admin`. Бот сам перезапускается при сбоях.

## Новое
- **Баннер «Выбери тэг»**: страница списка тегов в разделе собирается автоматически (`tags_template.png`) — названия тегов вписываются в плашки, пустые плашки стираются. Свой баннер страницы из админки главнее автоматического.
- **Оплата звёздами и бустами** (рядом с картой и голдой). Цены задаются в админке у каждого срока:
  `Срок | цена ₽ | цена голдой | ссылка | зв=50 | буст=3` (звёзды/бусты необязательны).
  Юзернейм, куда писать покупателю: `/admin → ⚙️ Настройки → ⭐/🚀 Юз…` (если пусто — пишет менеджеру).
- **Рефералки**: `/admin → 🔗 Рефералки → ➕ Создать ссылку`. Нажми на ссылку в списке — увидишь сколько человек перешло, сколько из них новые и сколько заказов выполнено.

- **Промокоды на конкретный тег**: при создании добавь 4-е поле — `КОД | скидка % | лимит | [ТЕГ]`. Без тега скидка на все товары. Привязать/отвязать готовый промокод можно в `/admin → 🎟 Промокоды → (код)`. Если у покупателя промокод на другой тег, цена там остаётся полной, а сам промокод не тратится.
